# Changelog

## 1.1.0 — 2026-10-03

- First public release as **Pocket — KDE Connect Bar**, originally developed locally as Pocket.
- Unique plugin ID: `io.github.oidium.pocket`.
- Automatic matching of Omarchy theme colors, fonts, spacing, and corners.
- Phone battery, connection state, direct storage shortcuts, notifications,
  media controls, file sharing, clipboard sharing, and phone ringing.
- Runtime dependency checks, including `sshfs` and `kio-fuse`, with setup guidance.
- Actionable errors for offline devices, unavailable folders and failed mounts.
